# Эмулятор оболочки UNIX

Эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом
(tkinter). Конфигурационное управление, практическая работа 1, вариант 6.
Нужен Python 3.10+ (tkinter входит в установку Python для Windows).

Запуск тестов на любом этапе: `python -m pytest`
(перед этим один раз `pip install -r requirements-dev.txt`).

## Этап 1. REPL

Минимальный прототип с диалогом с пользователем.

### Возможности

- графический интерфейс, в заголовке окна имя VFS (пока `vfs`)
- парсер делит ввод на команду и аргументы по пробелам
- команды-заглушки `ls` и `cd`
- команда `exit`
- обработка ошибок (неизвестная команда, неверные аргументы)

### Запуск

    python src/main.py

или `run.bat` (Windows), `./run.sh` (Linux/macOS).

## Этап 2. Конфигурация

Эмулятор настраивается параметрами командной строки.

### Параметры запуска

| Параметр | Описание |
|----------|----------|
| `--vfs-path` | путь к физическому расположению VFS |
| `--prompt` | приглашение к вводу |
| `--log-file` | путь к лог-файлу (XML) |
| `--script` | путь к стартовому скрипту |

### Возможности

- отладочный вывод всех параметров при запуске
- лог вызовов команд в XML с датой и временем
- стартовый скрипт, комментарии начинаются с `#`
- при выполнении скрипта видно и ввод, и вывод
- ошибка в скрипте выводится, выполнение продолжается дальше

### Запуск

    python src/main.py
    python src/main.py --prompt "emu> " --log-file logs/log.xml --script startup/stage2.txt

Скрипты ОС для проверки всех параметров: `scripts/stage2_*.sh`.

## Этап 3. VFS

Подключена виртуальная файловая система.

### Возможности

- VFS полностью хранится в памяти
- источник VFS - папка на диске (`--vfs-path`), файлы читаются как байты
- без параметра создается пустая VFS по умолчанию
- ошибки загрузки (папка не найдена, указан файл вместо папки)
- служебная команда `vfs-info` показывает дерево VFS

### Тестовые VFS

| Папка | Описание |
|-------|----------|
| `sample_vfs/minimal` | минимальная VFS (один файл) |
| `sample_vfs/several` | несколько файлов и папка |
| `sample_vfs/deep` | вложенность 4 уровня |

### Запуск

    python src/main.py
    python src/main.py --vfs-path sample_vfs/deep
    python src/main.py --vfs-path sample_vfs/deep --script startup/stage3_all.txt

Скрипты ОС со всеми вариантами VFS: `scripts/stage3_*.sh`.

## Этап 4. Основные команды

Реализована настоящая логика работы с VFS.

### Команды

| Команда | Описание |
|---------|----------|
| `ls [-a] [-l] [путь...]` | содержимое директории VFS |
| `cd [путь]` | смена директории (`..`, абсолютные и относительные пути) |
| `who [-H] [-q]` | текущий пользователь |
| `uname [-snrvmoa]` | информация о системе |

Приглашение по умолчанию показывает имя VFS и текущую папку.

### Запуск

    python src/main.py --vfs-path sample_vfs/several --script startup/stage4.txt

Другие скрипты: `startup/stage4_several.txt`, `startup/stage4_deep.txt`,
скрипты ОС `scripts/stage4_*.sh`.

## Этап 5. Дополнительные команды

Команды, изменяющие VFS (только в памяти, диск не трогается).

### Команды

| Команда | Описание |
|---------|----------|
| `mkdir [-p] путь...` | создает директории |
| `mv источник назначение` | переименовывает или переносит файл/папку |
| `mv источник... папка` | переносит несколько элементов в папку |

### Запуск

    python src/main.py --vfs-path sample_vfs/several --script startup/stage5_several.txt
    python src/main.py --vfs-path sample_vfs/deep --script startup/all_commands.txt

`startup/all_commands.txt` проверяет все команды всех этапов.
Скрипты ОС: `scripts/stage5_*.sh`, `scripts/all_commands.sh`.

## Структура

    src/         исходный код
    tests/       тесты
    startup/     стартовые скрипты эмулятора
    scripts/     скрипты ОС (.sh) для проверки параметров и VFS
    sample_vfs/  тестовые VFS

# Эмулятор оболочки ОС

Конфигурационное управление, практическая работа 1, вариант 6.
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом
(tkinter). Работает на Python 3.10+.

## Состояние проекта

Этап 1 (REPL): готов минимальный прототип с графическим окном.

## Возможности этапа 1

- окно с областью вывода и строкой ввода, заголовок содержит имя VFS
  (пока имя по умолчанию `vfs`);
- парсер делит ввод на команду и аргументы по пробелам;
- сообщения об ошибках: неизвестная команда, лишние аргументы;
- команды:
  - `ls [args...]` - заглушка, печатает свое имя и аргументы;
  - `cd [arg]` - заглушка, печатает свое имя и аргументы
    (больше одного аргумента - ошибка);
  - `exit` - закрывает эмулятор (с аргументами - ошибка).

## Сборка и запуск

Зависимости для запуска не нужны, нужен только tkinter
(в Linux: `sudo apt install python3-tk`).

```
python3 src/main.py      # или ./run.sh, run.bat в Windows, make run
```

Тесты и проверка стиля:

```
pip install -r requirements-dev.txt
python3 -m pytest        # или make test
python3 -m flake8 --max-line-length 80 src tests   # или make lint
```

Тесты окна требуют дисплей, без него они пропускаются
(на сервере можно запустить через `xvfb-run -a python3 -m pytest`).
Файл `tests/test_style.py` проверяет правила оформления из задания:
длина строк, размер функций, число аргументов, сложность, docstring,
магические числа в сравнениях, имена по PEP8.
